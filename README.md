# Monitoring Stack Setup using Prometheus, Grafana, Node Exporter, Alertmanager, and PagerDuty

https://github.com/user-attachments/assets/65938448-2920-4cad-a36d-8c6d3c3997ff

## Overview

This project provides a complete monitoring and alerting solution using:

* Node Exporter
* Prometheus
* Grafana
* Alertmanager
* PagerDuty

The setup is automated using shell scripts, making deployment simple on Linux-based systems.

The monitoring stack enables:

* Server health monitoring
* Metrics collection
* Dashboard visualization
* Alert generation
* Incident management and notification

# Components Overview

## 1. Node Exporter

### Purpose

Node Exporter collects operating system and hardware metrics from Linux servers.

Examples:

* CPU Usage
* Memory Usage
* Disk Usage
* Network Statistics
* File System Information

Node Exporter exposes these metrics through:

```text
http://<server-ip>:9100/metrics
```

### Responsibilities

* Collect server metrics
* Expose metrics via HTTP
* Allow Prometheus to scrape system data

### Installation

Run:

```bash
./node.sh
```

### Result

Node Exporter starts on:

```text
Port: 9100
```

---

## 2. Prometheus

### Purpose

Prometheus is the central monitoring engine.

It continuously collects metrics from Node Exporter and stores them inside its Time Series Database (TSDB).

### Responsibilities

* Scrape metrics from targets
* Store metrics
* Execute PromQL queries
* Evaluate alert rules
* Send alerts to Alertmanager

### Workflow

Every configured scrape interval (15 seconds):

```text
Prometheus
      |
      v
Node Exporter
```

Prometheus fetches metrics such as:

```text
CPU Usage
Memory Usage
Disk Usage
Network Usage
```

These metrics are stored inside TSDB.

### Access

```text
http://<server-ip>:9090
```

---

## 3. Grafana

### Purpose

Grafana provides dashboards and visualizations for Prometheus metrics.

### Important Note

Grafana does NOT collect metrics.

Instead:

```text
Grafana ---> Prometheus
```

Grafana sends PromQL queries to Prometheus and displays the returned data as:

* Graphs
* Gauges
* Tables
* Stat Panels

### Responsibilities

* Visualize metrics
* Build dashboards
* Create alert rules
* Display system health

### Access

```text
http://<server-ip>:3000
```

Default Credentials:

```text
Username: admin
Password: admin
```

---

## 4. Alertmanager

### Purpose

Alertmanager handles alerts generated by Prometheus.

### Responsibilities

* Receive alerts
* Group alerts
* Deduplicate alerts
* Silence alerts
* Route alerts to receivers

Supported Receivers:

* PagerDuty
* Email
* Slack
* Microsoft Teams
* Webhooks

### Workflow

```text
Prometheus
      |
      | Alert
      v
Alertmanager
```

Example:

```text
High CPU Usage
Instance Down
High Memory Usage
```

### Access

```text
http://<server-ip>:9093
```

---

## 5. PagerDuty Integration

### Purpose

PagerDuty is an incident management platform used for notifying on-call engineers.

### Workflow

```text
Prometheus
      |
      v
Alertmanager
      |
      v
PagerDuty
      |
      v
Engineer Notification
```

### Notification Channels

PagerDuty can notify through:

* Mobile Push Notifications
* SMS
* Phone Calls
* Email

### Configuration

Example Alertmanager receiver:

```yaml
receivers:
  - name: pagerduty
    pagerduty_configs:
      - routing_key: <PAGERDUTY_INTEGRATION_KEY>
```

### Benefits

* Real-time incident response
* On-call scheduling
* Escalation policies
* Incident tracking

# Alerting Workflow

Example Alert Rule:

```yaml
alert: InstanceDown
expr: up == 0
for: 1m
```

### What Happens?

1. Prometheus checks the target.
2. Target becomes unavailable.
3. `up` metric becomes `0`.
4. Condition remains true for 1 minute.
5. Alert enters FIRING state.
6. Alert sent to Alertmanager.
7. Alertmanager sends notification to PagerDuty.
8. PagerDuty notifies the on-call engineer.

# Useful Grafana Dashboard Queries

## CPU Usage %

```promql
100 - (avg by(instance) (rate(node_cpu_seconds_total{mode="idle"}[5m])) * 100)
```

---

## Top 5 High CPU Servers

```promql
topk(5,
100 - (avg by(instance) (rate(node_cpu_seconds_total{mode="idle"}[5m])) * 100)
)
```

---

## Memory Usage %

```promql
(1 - (node_memory_MemAvailable_bytes / node_memory_MemTotal_bytes)) * 100
```

---

## Memory Used (GB)

```promql
(node_memory_MemTotal_bytes - node_memory_MemAvailable_bytes) / 1024^3
```

---

## Disk Usage %

```promql
(1 - (
node_filesystem_avail_bytes{fstype!~"tmpfs|overlay"}
/
node_filesystem_size_bytes{fstype!~"tmpfs|overlay"}
)) * 100
```

---

## Disk Read Rate

```promql
rate(node_disk_read_bytes_total[5m])
```

---

## Disk Write Rate

```promql
rate(node_disk_written_bytes_total[5m])
```

---

## Network Incoming Traffic

```promql
rate(node_network_receive_bytes_total[5m])
```

---

## Network Outgoing Traffic

```promql
rate(node_network_transmit_bytes_total[5m])
```
